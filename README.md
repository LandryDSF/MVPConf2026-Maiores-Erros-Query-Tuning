## Os Maiores Erros de Query Tuning no SQL Server - Nem Sempre é Falta de Índice

Repositório oficial com os scripts apresentados na palestra do **Prof. Landry Duailibe Salles Filho**.

---

**🗓️ 26/09/2026 – 14h | Sala 109**
Quando uma consulta está lenta, uma das primeiras reações costuma ser procurar por um índice ausente. Mas Query Tuning vai muito além da criação de índices.

Nesta palestra, apresentamos uma visão mais ampla dos principais fatores que podem impactar o desempenho de consultas no SQL Server, incluindo recursos da instância, projeto físico, índices e estatísticas, escrita das consultas e concorrência.

Na parte prática, o foco é a escrita das consultas e como pequenas decisões no código podem impedir o SQL Server de utilizar os índices de forma eficiente.

Os hands-ons demonstram, na prática, problemas comuns como:
- Consultas SARGable x Non-SARGable
- Conversões implícitas
- Operações aritméticas aplicadas sobre colunas

A ideia principal é mostrar que, muitas vezes, o índice correto já existe — o problema está na forma como a consulta foi escrita.
